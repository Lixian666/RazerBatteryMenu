# 安装与故障排查

## 系统要求

- macOS 13 Ventura 或更高版本；
- 当前发布包面向 Apple Silicon；
- Basilisk V3 Pro 普通版 2.4G 接收器 `1532:00AB`，或等待验证的有线 `1532:00AA`。

## 使用 DMG 安装

1. 从 GitHub Releases 下载 `.dmg`。
2. 打开镜像，将 `RazerBatteryMenu.app` 拖到“应用程序”。
3. 从“应用程序”启动。应用只显示在菜单栏，不显示在 Dock。
4. 打开面板，按提示授权“输入监控”。

建议先将应用移动到“应用程序”再开启“登录时启动”，避免路径变化导致系统保存旧位置。

## 输入监控权限

路径：**系统设置 → 隐私与安全性 → 输入监控**。

该权限让应用打开雷蛇 HID 控制接口。应用不会记录、持久化或上传鼠标移动和键盘输入。授权后返回应用，应用会自动重新枚举设备。若 macOS 要求退出应用，请按系统提示重新启动。

重新编译或替换 ad-hoc 签名的应用可能改变系统识别身份，需要重新授权。正式 Developer ID 签名的连续版本可减少这种情况。

## Gatekeeper

未公证的测试构建可能被阻止。请在“系统设置 → 隐私与安全性”中检查被阻止的应用并选择“仍要打开”，或右键应用选择“打开”。

不要关闭 Gatekeeper、系统完整性保护，也不要修改 TCC 数据库。

## 常见状态

| 状态 | 含义 | 建议 |
|---|---|---|
| 未连接 | 接收器或有线设备没有枚举到 | 检查 USB 连接、Hub 和接收器 |
| 需要输入监控权限 | macOS 拒绝打开 HID 接口 | 在系统设置授权后返回应用 |
| 暂不可读 | 权限、接口占用或通信错误 | 退出其他鼠标管理软件后刷新 |
| 休眠待机 | 接收器仍在，但鼠标休眠 | 移动鼠标会触发即时刷新 |
| 型号暂未支持 | 识别到非白名单产品 ID | 提交脱敏诊断信息协助适配 |

## 菜单栏图标不可见

- 确认应用位于“活动监视器”的进程列表；
- 检查菜单栏空间，刘海屏可能隐藏靠左的状态项目；
- 退出旧版本后再启动“应用程序”中的版本；
- 若应用立即退出，请附上 `~/Library/Logs/DiagnosticReports/` 中对应的崩溃报告提交 Issue，先移除个人路径和设备标识。

## 卸载

1. 在应用面板中关闭“登录时启动”；
2. 退出应用并删除 `RazerBatteryMenu.app`；
3. 如需删除偏好设置，执行：

```bash
defaults delete app.razerbatterymenu.macos
```
